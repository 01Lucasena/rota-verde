# 🚲 Rota Verde

Landing page para um serviço fictício de entregas sustentáveis por bicicleta, feita para lojas e restaurantes de bairro. Projeto desenvolvido para praticar HTML semântico, CSS responsivo, JavaScript puro e boas práticas de SEO on-page.

🔗 **Demo ao vivo:** [rotaverdels.netlify.app](https://rotaverdels.netlify.app)

## Funcionalidades

- Layout 100% responsivo (mobile, tablet e desktop)
- Menu de navegação com hambúrguer funcional no mobile
- Seção "Como funciona" com passos ilustrados
- Cards de benefícios com hover
- Formulário de contato com validação em JavaScript (campos obrigatórios + validação de email)
- Meta tags de SEO (description, canonical, Open Graph)

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Flexbox, media queries)
- JavaScript (vanilla, sem frameworks)
- [Boxicons](https://boxicons.com/) para ícones
- [Google Fonts](https://fonts.google.com/) — Fraunces + Work Sans

## Como rodar localmente

```bash
git clone https://github.com/01Lucasena/rota-verde.git
cd rota-verde
```

Depois é só abrir o `index.html` no navegador (ou usar a extensão Live Server do VS Code).
